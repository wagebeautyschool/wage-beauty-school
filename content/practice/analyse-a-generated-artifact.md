## Question

If you take one AI output apart, what is actually holding it up?

## Context

A generated artifact arrives whole and fluent, which makes it hard to see the seams. This exercise is a way of forcing the seams back into view. Pair it with the Library note [On Generated Artifacts](entry.html?c=library&id=on-generated-artifacts).

## Exercise

Take a single output — a paragraph, an image, a plan, a snippet of code. Work through it in writing:

1. **The claim.** State the implied assertion the artifact is making. *This is accurate / good / complete / what you asked for.*
2. **The load-bearing parts.** Identify the three or four specific elements doing the real work — a figure, a name, a causal link, a key design choice.
3. **Verification.** Check each load-bearing part against a source that is not another generation. Note what held and what did not.
4. **The unexamined assumption.** Find at least one thing the artifact took for granted because your prompt did.
5. **The smoothing.** Find a place where a real disagreement or difficulty was flattened into a confident middle.

## Reflection

Would you put your name on this now, unedited? If not, list what would have to change first. That list is the difference between using the instrument and being used by it.
